# FGO_ranking_calculator

FGO @wiki / siroi_human @wiki のサーヴァント性能データを解析し、共通条件でランキング表示するための計算基盤です。

## データソース

- 公式: https://w.atwiki.jp/f_go/pages/671.html
- オリジナル: https://w.atwiki.jp/siroi_human/pages/54.html
  - `サーヴァント` 見出し以下の一覧のみを収集起点に使用します。
  - `データ` 見出し以下はフレーバーテキストのためランキングには使用しません。
  - 一覧の打ち消し線は性能データ欠損を意味しないため除外条件にしません。

## 現在の実装

- HP / ATKランキング（最大Lv / Lv100 / Lv120、フォウ0 / +1000 / +2000）
- N/A・N/D・スター発生率・各カードHit数の解析
- 通常攻撃NPランキング
- 通常攻撃スター期待値ランキング
- 宝具解析（カード種、単体/全体、Hit数、宝具Lv倍率、攻撃前後効果）
- 宝具NPリチャージランキング
- 宝具ダメージランキング（乱数0.900～1.099の200通りから最低/平均/最高を算出）
- 保有スキル / クラススキル解析
- 強化後スキル優先
- 条件付き効果ON/OFF
- 確率効果メタデータ
- 宝具OC依存の攻撃前効果
- 特攻効果の明示的除外
- スキルあり通常NP / スター / 宝具NP / 宝具ダメージ
- バフ量ランキング（自身 / 味方、攻撃/B/A/Q/宝具威力/Crit/NP獲得/スター発生率）
- 3Waveシステム成立判定
  - 各Waveの宝具使用直前NPが100%以上かで判定
  - 宝具リチャージ＋NP付与＋毎ターンNPを合算
  - Quickの基本形 `50%リチャージ + 50%付与 = 100%` を正式に成立扱い
  - `49% + 50% = 99%` は不成立として回帰テスト済み
  - Waveごとのスキル使用順、CT経過、CT短縮を処理
  - 現在NP比例のNP増加（ルシフェラS3等）に対応
  - 個別ページから解析した自前NPチャージをシステム行動へ変換
  - 自動行動探索で3連射可能なスキル使用Waveを決定
- システムプリセット
  - アルトリア〔キャスター〕Arts
  - バフォメットArts
  - 水着スカサハ＝スカディQuick
  - 支配のフォーリナーQuick / 〔クトゥルフ〕
  - W光のコヤンスカヤBuster
  - 光コヤン＋オベロンBuster
  - WルシフェラBuster
  - ルシフェラ＋オベロンBuster
- システム用特殊バフ
  - カード性能アップ効果量ブースト
  - 宝具威力アップ効果量ブースト
  - OC段階上昇
- システムNP回収ランキング
  - Wave別敵数 / DTDR / オーバーキルHit数対応
  - 旧ランキング互換の初期OK Hitは `ceil(Hit / 2)`
- システム宝具ダメージランキング
  - Wave1 / Wave2 / Wave3それぞれ最低・平均・最高ダメージを算出
  - 1W / 2W / 3W / 3Wave合計平均で並べ替え可能
  - 旧ランキング基準の宝具Lv（★3以下NP5、★4以上NP2）を選択可能
  - 配布NP5は `welfarePageIds` 指定で対応

### システムランキングの次工程

現在のWave別ダメージでは、サポータープリセットのバフはWaveごとに反映済みです。アタッカー自身の保有スキルは、使用Wave・持続ターン・CT再使用まで含めて最適化した後に接続します。これにより「全スキルが全Waveで常時有効」という誤計算を避けます。

計算式は `siroihuman/FGO_Battle_Simulator_Work` を基準に同期します。
